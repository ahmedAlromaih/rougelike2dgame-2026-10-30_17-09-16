# Rougelike 2d game

A 2D roguelike game project developed with **Unity** and **C#**.

## Requirements

- [Unity Hub](https://unity.com/download)
- The Unity Editor version specified in `ProjectSettings/ProjectVersion.txt` (recommended)
- macOS or Windows

## Download the project

1. Open the [GitHub repository](https://github.com/ahmedAlromaih/rougelike2dgame-2026-10-30_17-09-16).
2. Select **Code > Download ZIP**.
3. Extract the ZIP file to a folder on your computer.

Alternatively, clone it with Git:

```bash
git clone https://github.com/ahmedAlromaih/rougelike2dgame-2026-10-30_17-09-16.git
```

## Open the project in Unity

1. Launch **Unity Hub**.
2. Open the **Projects** tab and choose **Add > Add project from disk**.
3. Select the downloaded or cloned repository folder (the folder containing `Assets`, `Packages`, and `ProjectSettings`).
4. If prompted, install the project's required Unity Editor version.
5. Open the project and wait for Unity to import its assets.

## Run the game

1. In the Unity Editor, find the game scene in the **Project** window. You can search for scenes using `t:Scene`.
2. Double-click the scene to open it.
3. Click the **Play** button at the top of the editor.
4. Click **Play** again to stop.

> **Note:** This repository contains a Unity project, not a prebuilt executable. Open it in Unity to run or modify the game. The exact main scene and Unity Editor version should be checked in the project.

## Repository structure

```text
Assets/           Game scenes, scripts, sprites, and other assets
Packages/         Unity package configuration and dependencies
ProjectSettings/  Unity project settings and editor version
.gitignore        Git ignore rules
```

## Troubleshooting

- **Unity version mismatch:** Check `ProjectSettings/ProjectVersion.txt` and install that version through Unity Hub.
- **Missing assets or packages:** Make sure you downloaded the entire repository, not only the `Assets` folder.
- **Nothing happens when you press Play:** Open a game scene first, then press Play.
- **First launch takes time:** Unity may need to import assets and resolve packages.
